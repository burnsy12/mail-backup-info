Personal desktop software

A private backup of my email.

Greg's Mail Backup is a personal desktop tool operated by Greg Burns. It creates a recoverable copy of his own Gmail messages and mailbox metadata.

What the application does

  • Reads messages, attachments, drafts, labels and message metadata from explicitly authorised Gmail accounts.
  • Saves messages as EML files or monthly ZIP archives, with SQLite metadata snapshots.
  • Publishes backup files to the owner's Microsoft OneDrive folder after local verification.
  • Tracks mailbox changes and permanent deletions on subsequent successful runs.

Read-only Google access

The backup connection requests Gmail read-only access through Google's OAuth consent flow. Backup runs do not send, delete or modify messages in Gmail.

The software runs on the owner's Windows computer. This website does not connect to Gmail, request Google sign-in or receive backup content.

Private use

This is an owner-operated tool for personally controlled accounts. It is not a public account-registration or hosted backup service.

Read the privacy policy for data access, storage and deletion details, and the terms of use for the scope of this personal application.
